# Rigoutech

Site statique du studio Rigoutech, à Montréal.

## Aperçu

Le flux d’aperçu des pull requests construit le dossier `dist/` et le publie sur le site GitHub Pages du dépôt. Cet aperçu ne doit pas être branché sur rigoutech.com tant que la mise en production n’est pas décidée. Le fichier `CNAME` n’est pas copié dans `dist/`.
